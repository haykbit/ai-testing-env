# Triage labels

The engineering skills use these five canonical workflow roles:

| Role | GitHub label | Meaning |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | A maintainer must evaluate the issue. |
| `needs-info` | `needs-info` | Work is waiting for information from the reporter. |
| `ready-for-agent` | `ready-for-agent` | The issue is fully specified and can be implemented without additional context. |
| `ready-for-human` | `ready-for-human` | The issue needs human implementation or judgment. |
| `wontfix` | `wontfix` | The issue will not be actioned. |

Use exactly one workflow label when triaging an issue and replace the previous
workflow label when its state changes.
