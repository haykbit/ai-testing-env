# Domain docs

This repository has a single domain context.

## Before exploring or changing the system

- Read the domain language and architectural rules in `AGENTS.md`.
- Read relevant decisions in `docs/adr/`.
- Read `CONTEXT.md` if one is introduced later.

Use the established terms Project, Scenario, Flow, Step, Run, Trace,
Evaluation, Verdict, and Profile in issues, tests, code, and documentation. Do
not introduce synonyms for these concepts without first documenting the new
language.

If proposed work conflicts with an accepted ADR, surface that conflict
explicitly rather than silently overriding the decision.
